# Research

- 2026-06-09: Browser-local transcription model pass. `onnx-community/whisper-small` is directly Transformers.js-compatible and improves quality over `onnx-community/whisper-base` while remaining multilingual. Use `q8` dtype by default to keep the mobile/browser download and memory profile lower than fp32/fp16. `distil-whisper/distil-small.en` is lighter/faster for English-only voice notes, but do not switch to it without confirming English-only transcription is acceptable for the community.
- 2026-06-09: Cloudflare Workers AI transcription pass. Workers AI uses an `ai` binding exposed as `env.AI.run(...)`; the Cloudflare Whisper large v3 turbo model id is `@cf/openai/whisper-large-v3-turbo`, accepts base64 audio plus optional language/prompt/VAD controls, and is priced by audio minute. Workers request body limits are plan-dependent, while Workers still have 128 MB memory, so keep app-level audio upload size limits conservative.
- 2026-06-10: Daily usage limit implementation pass. Cloudflare Worker `vars` are appropriate for non-secret numeric deployment limits. D1 `batch()` is documented as sequential and transactional, so message usage reservation and message insert can share a batch to avoid consuming quota if the insert fails.
- 2026-06-12: PWA update recovery pass. MDN documents `ServiceWorkerRegistration.update()` as the standard explicit update check, `unregister()` as the standard registration removal, and `CacheStorage.delete()` as the browser Cache Storage cleanup primitive. Vite PWA documents hourly guarded checks through `onRegisteredSW` plus `fetch(swUrl, { cache: "no-store" })` before `registration.update()`. Workbox documents `cleanupOutdatedCaches` for obsolete precaches and `clientsClaim()` with `skipWaiting()`. Cloudflare Workers Static Assets default to `Cache-Control: public, max-age=0, must-revalidate`, and `_headers` can override static asset headers from `public/`.
